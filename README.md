# NeoMundi RiCo Observation-to-Admissibility Pilot

**Status:** Private exploratory research repository.

This repository documents exploratory research at the Runtime Execution Boundary (REB), where runtime observation, admissibility, execution legitimacy, and reconstructable governance intersect.

The pilot explores how Runtime Integrity Control (RiCo) can preserve continuously accountable execution by evaluating whether runtime actions remain legitimate, authorized, and aligned with present conditions.

This repository is intended for architectural research and documentation.

It is **not**:
- a production system,
- a certification framework,
- a compliance mechanism,
- an approval authority,
- or a decision-making system.

Its purpose is to investigate how runtime governance can preserve reconstructable governance receipts, execution integrity, and admissibility throughout the operational lifecycle of intelligent systems.

## Architectural Alignment

- REB = Runtime Execution Boundary
- RiCo = Runtime Integrity Control
- CARE/REB = Runtime execution boundary architecture (naming depends on current use)
